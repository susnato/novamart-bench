You are evaluating whether a generated tribal knowledge book contains one gold atomic claim.

Gold evidence explains why the gold claim is true.
Do NOT count gold evidence as evidence in the book.
Only score what the book itself says.

claim_text states the claim in full and defines its meaning.
The main finding is what the match.must_include points jointly state, anchored in the first sentence of claim_text together with the specifics that identify it (the quantities, dates, names, tables, values or mechanism that make it this finding and not a similar one). It is not the claim's topic or headline. A book that only says the topic exists, or gives a generic description of it, has not stated the finding.
match.must_include lists the points to look for in the book. A point counts when its meaning is in the book, as defined below; exact wording is not required. Details that appear in claim_text but not in must_include (definitions of terms, resumption dates, extra figures, the mechanism behind a point that is already found) are not required and must never be used to lower a point or the main finding.
Use match.must_not_include to detect contradictions. A forbidden point is found only when the book asserts its meaning, that is, the opposite of what the claim says. Compare meaning, not keywords. A book that omits a detail, describes a neutral default or fallback, or gives a general formula next to documented exceptions or warnings does not assert a forbidden point.

A must_include point is found when its meaning is present in the book, in any wording:
- Each distinct element a point names (a count, a value, a cause, a date, a fix or its behavior, "never refreshed", "no reader", "verified in the log") must be stated or clearly entailed by the book's own words. A generic mention of the topic, an adjacent fact, or a neighbouring source does not carry a specific element. A fact about a different version, job, table or period does not carry the point.
- A point that joins several facts is found when the book states each of its elements. A half-met point is not found when the missing half is a separate fact the point names. It is found only when the missing half is a mere restatement or precision of what the book says.
- A numeric point is found when the book gives the same quantity and the same rule behind it, even if the value is shifted or stale. It is not found when the number implies a different rule or threshold, or when the quantity is absent.
- The parts of a point may sit in different places in the book. Read the book as a whole and combine them; a point is found when the pieces together state its meaning, wherever they appear.
- A point about a formula or rule is found when the book expresses the same relationship with all of its parts, such as coefficients, weights or thresholds, in words or in any other form. The exact formula is not required.
- A negative point ("not an experiment", "no overlap", "read by nothing", "never occurs") is found when the book's stated facts entail it: the positive facts that exclude it are given, such as a single switch date with the old version retired, or no definition, no writer and zero rows across the whole history. A different label for the same state does not block it. An unrelated arm, group or path in the book does not contradict an absence unless the book says it plays the role the point rules out. It is not found when the book only gives adjacent facts that leave it open, or when the zero is only about a current or partial slice.

Main finding grading:
- "full" when every must_include point is found, or when each missing point is only a restatement or finer precision of a found one. If every point is found, the grade is "full" whatever claim_text details are absent.
- "part" when the identifying core is stated but at least one must_include point that names a separate fact (a count, a value, a cause, a date, a fix, a verification, or the scope such as "every month") is not found. Do not call it "full" because the book covers the topic or the headline while a named separate fact is missing.
- "none" when the book does not state the first-sentence finding with its specifics, or states only the topic or facts about a neighbouring version, job or table. When most must_include points are not found, the grade is at most "part".

Work in this order:
1. Read the whole book first. List every passage that touches the topic of the claim: quote each passage and name the section it comes from. The passages that matter are often spread across the book.
2. State the claim's main finding in one sentence, with its identifying specifics.
3. For each must_include point, in the order given, decide from those passages whether its meaning is present. Quote the passage or passages that carry it; if nothing in the book carries it, write "none" and set found to false. Do the same for each must_not_include point.
4. Decide whether the book states the main finding: "full" when the book states it with its identifying specifics, "part" when the book states it only in part or without the specifics that identify it, "none" when the book does not state it, even if it states other must_include points.
5. The most common error on this task is calling a point not found when the book does state it, in other words or in another place. Before you set found to false for any point, search the book once more for it.

The verdict is computed from your decisions: contradicted if any must_not_include point is found; otherwise correct when the main finding is "full", even if a must_include point that explains, refines or quantifies it is not found; partial when the main finding is "part"; missing when the main finding is "none". Fill in verdict with your own call as well.

points must have exactly one entry per must_include point, in the same order. forbidden_points must have exactly one entry per must_not_include point; use an empty list when there are none.

book_evidence is separate from the verdict and only records how the book supports what it says: specific when the book points to a concrete source for the claim (a code path, a table or query, a dashboard, an experiment, or a reference), weak when it supports the claim without a concrete source, none when it only states the fact or omits it.
