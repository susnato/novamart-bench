You are evaluating whether a generated tribal knowledge book contains one gold atomic claim.

Gold evidence explains why the gold claim is true.
Do NOT count gold evidence as evidence in the book.
Only score what the book itself says.

claim_text states the claim in full and defines its meaning.
Every claim has a main finding: the fact the claim exists to establish. It is stated in the first sentence of claim_text together with the specifics that identify it (the quantities, dates, names or tables that make it this finding and not a similar one). The rest of claim_text and the later must_include points add the cause, the mechanism, a precise figure, a procedure, or a proof that something is absent.
match.must_include lists the points to look for in the book. A point counts when its meaning is in the book, as defined below; exact wording is not required. Details that appear in claim_text but not in must_include, including numbers, are not required, and you must not demand them when deciding a point or the main finding.
Use match.must_not_include to detect contradictions. A forbidden point is found only when the book clearly asserts it. A different wording of the same outcome, or a different account that leads to the same result the claim describes, is not a contradiction.

A must_include point is found when its meaning is present in the book, in any wording:
- A point that joins several facts is found when the book states the fact the point exists to check. Two expressions of the same quantity are interchangeable. A half-met point is not found only when the missing half changes the meaning of the claim.
- A numeric point is found when the book gives the same quantity and the same rule behind it, even if the value is shifted or stale. It is not found when the number implies a different rule or threshold.
- The parts of a point may sit in different places in the book. Read the book as a whole and combine them; a point is found when the pieces together state its meaning, wherever they appear.
- A point about a formula or rule is found when the book expresses the same relationship with all of its parts, such as coefficients, weights or thresholds, in words or in any other form. The exact formula is not required.
- When the book states facts that plainly entail a point (a single switch date with the old version retired, a status listed as excluded and as absent from the data, a status absent from every observed count), the point is found even if the negative or the label is not spelled out. Extra labels or hedges that do not change the facts do not undo it.
- Do not infer a point from silence. If the book never says the thing itself, and only a neighbouring fact (a different table, a different surface, a generic remark about missing reports, a commit cited without its description), the point is not found.
- A point that names a separate fact is found only when the book states that fact: who or what created something, how a fix works, where evidence can be checked, what the displayed measure is, what a field does not record, or what was decided. Another fact about the same object does not stand in for it.

Deciding the main finding (step 4):
- "full" requires the identifying specifics of the first sentence AND every must_include point that states a separate fact of the kinds listed above. A missing point that only supplies a count, a value, or a date span does not lower "full".
- If any such separate-fact point is not found, the main finding is "part", even when the headline fact is present.
- Do not lower "full" to "part" because of details outside the must_include points, such as a mechanism name, an exact total, a commit, or wording like "silent" or "deliberate", when the book states the facts that carry the same meaning.
- "none" applies when the headline fact itself is absent or the book says the opposite.

Work in this order:
1. Read the whole book first. List every passage that touches the topic of the claim: quote each passage and name the section it comes from. The passages that matter are often spread across the book.
2. State the claim's main finding in one sentence, with its identifying specifics.
3. For each must_include point, in the order given, decide from those passages whether its meaning is present. Quote the passage or passages that carry it; if nothing in the book carries it, write "none" and set found to false. Do the same for each must_not_include point.
4. Decide whether the book states the main finding: "full" when the book states it with its identifying specifics, "part" when the book states it only in part or without the specifics that identify it, "none" when the book does not state it, even if it states other must_include points.
5. The most common error on this task is calling a point not found when the book does state it, in other words or in another place. Before you set found to false for any point, search the book once more for it.

The verdict is computed from your decisions: contradicted if any must_not_include point is found; otherwise correct when the main finding is "full", even if a must_include point that explains, refines or quantifies it is not found; partial when the main finding is "part"; missing when the main finding is "none". Fill in verdict with your own call as well.

book_evidence is separate from the verdict and only records how the book supports what it says: specific when the book points to a concrete source for the claim (a code path, a table or query, a dashboard, an experiment, or a reference), weak when it supports the claim without a concrete source, none when it only states the fact or omits it.
