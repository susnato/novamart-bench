# Rater decision rules

Verbatim from the labelling study (October 2026). The fill list named in note P2 is recorded in `sampling.json`.

Rules the rater fixed while labelling, in the order they came up. Each rule applies to every cell from the moment it was written and is never revised for a later cell. Released with the labels.

| Rule | Decided at | Situation | Rule |
|---|---|---|---|
| R1 | cell 23 of 300 (2026-10-11) | A must-include point is compound (two facts joined by "and", for example a count and a revenue figure) and the book states only one of them. | The point counts as found when the book states the fact the point exists to check. Two expressions of the same quantity (units and revenue of the same row) are interchangeable: either one satisfies the point. A half-met point lowers the verdict to partial only when the missing half changes the meaning of the claim. |

| P1 | 100 of 300 labelled (2026-10-13) | If labelling stops before all 300 cells are filled, the labelled set is, for every book, a prefix of that book's rows in the seeded sheet order (rows within a book were shuffled by the kit seed, so a prefix is a seeded random subset). Books E to I are labelled breadth-first: a first pass of about 20 rows per book, then further rows per book as time allows, so that every book, and therefore every entry, is represented. The analysis reweights by judge-label stratum as before; no cell is chosen or skipped by content. |
